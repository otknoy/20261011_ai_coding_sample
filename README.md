# 品貸料率 上位20件

Python 3（追加ライブラリ不要）で、日本証券金融のCSVから品貸料率の高い20件を表示します。

コードの処理内容は [コード解説](CODE_GUIDE.md) を参照してください。

```bash
python3 shina_top20.py
```

実行のたびに https://www.taisyaku.jp/data/shina.csv を取得し、`銘柄名` と `当日品貸料率（円）` の2列をターミナルに表示します。

- 料率は数値として降順に並べ、同率はCSVの掲載順を維持します。
- `*****` や空欄などの非数値は除外します。0円は含めます。
- 有効な行が20件未満なら全件表示します。
- 配布中のデータを使うため、必ずしも実行当日の日付のデータではありません。
- 通信は30秒でタイムアウトします。取得失敗や必要な列の欠落時はエラーを表示し、終了コード1で終了します。

確認用テスト:

```bash
python3 -m unittest -v
```
